# راهنمای مدیریت محتوای لندینگ پیج عمومی

این پوشه محتوای وب‌سایت عمومی کارخانه (اخبار، اطلاعیه‌ها، گزارش‌ها، دربارهٔ ما) را نگه می‌دارد.
مطابق بخش ۹.۱۰.۱ سند PRD، این محتوا **کاملاً مستقل از دیتابیس و پنل ادمین** است و مستقیماً
از همین فایل‌ها خوانده می‌شود. پس از هر تغییر و Deploy، صفحات به‌صورت خودکار به‌روزرسانی می‌شوند
(Next.js SSG/ISR با `revalidate: 3600`).

> این بخش برای «پشتیبان فنی سایت» است که به مخزن کد دسترسی دارد؛ نیازی به دانش برنامه‌نویسی نیست،
> فقط ویرایش فایل‌های متنی.

## ساختار پوشه‌ها

```
apps/web/content/
├── news/                # اخبار کارخانه (هر خبر = یک فایل .md)
├── announcements/       # اطلاعیه‌ها (هر اطلاعیه = یک فایل .md)
├── reports/             # گزارش‌ها (هر گزارش = یک فایل .md، معمولاً با فایل PDF ضمیمه)
└── about.mdx            # دربارهٔ ما (تک‌فایل)

apps/web/public/media/
├── photos/              # عکس‌ها + فایل photos.json (عنوان/توضیح هر عکس)
├── videos/              # فایل videos.json (لینک Embed آپارات/یوتیوب)
└── reports/             # فایل‌های PDF ضمیمهٔ گزارش‌ها
```

## افزودن یک خبر جدید

۱. یک فایل جدید در `content/news/` بسازید. نام فایل را به‌صورت `YYYY-MM-DD-عنوان-انگلیسی.md` بگذارید
   (مثلاً `2026-08-01-new-contract.md`). بخش نام فایل بعد از تاریخ، به‌عنوان نشانی صفحه (slug) استفاده می‌شود.

۲. در ابتدای فایل، بخش «Frontmatter» را بین دو خط `---` قرار دهید:

```markdown
---
title: عنوان خبر
date: 2026-08-01
summary: یک خلاصهٔ کوتاه که در کارت لیست نمایش داده می‌شود.
cover: /media/photos/my-photo.jpg
---

## تیتر داخل متن

متن کامل خبر اینجا نوشته می‌شود...
```

- `title` (الزامی): عنوان خبر
- `date` (الزامی): تاریخ انتشار به‌صورت `YYYY-MM-DD` (میلادی). مبنای مرتب‌سازی (جدیدترین بالا) و نمایش تاریخ جلالی.
- `summary` (اختیاری): خلاصه برای کارت لیست
- `cover` (اختیاری): مسیر تصویر Cover؛ ابتدا عکس را در `public/media/photos/` بگذارید و مسیر آن را با `/media/photos/...` بنویسید.

## افزودن اطلاعیه

مثل خبر، اما در پوشهٔ `content/announcements/`. معمولاً بدون تصویر Cover.

## افزودن گزارش (با فایل PDF)

۱. فایل PDF را در `public/media/reports/` بگذارید (مثلاً `report-1405.pdf`).
۲. یک فایل `.md` در `content/reports/` بسازید و در Frontmatter آن، مقدار `attachment` را به مسیر PDF اشاره دهید:

```markdown
---
title: گزارش عملکرد ۱۴۰۵
date: 2026-09-01
summary: خلاصهٔ گزارش
attachment: /media/reports/report-1405.pdf
---

توضیح کوتاه گزارش...
```

دکمهٔ «دانلود PDF» به‌صورت خودکار در صفحهٔ گزارش‌ها نمایش داده می‌شود.

## افزودن عکس به گالری

۱. فایل عکس را در `public/media/photos/` بگذارید.
۲. در فایل `public/media/photos/photos.json` یک ورودی جدید اضافه کنید:

```json
{
  "src": "/media/photos/my-photo.jpg",
  "title": "عنوان عکس",
  "description": "توضیح کوتاه"
}
```

## افزودن ویدیو به گالری

فایل `public/media/videos/videos.json` را ویرایش کنید. برای هر ویدیو، لینک Embed آپارات یا یوتیوب را بگذارید:

```json
{
  "title": "عنوان ویدیو",
  "description": "توضیح",
  "provider": "aparat",
  "embedUrl": "https://www.aparat.com/video/video/embed/videohash/XXXX/vt/frame",
  "thumbnail": "/media/photos/thumb.jpg"
}
```

## نوشتن متن (Markdown)

متن بدنه با قالب سادهٔ Markdown نوشته می‌شود:

- `# عنوان بزرگ` ، `## عنوان متوسط` ، `### عنوان کوچک`
- `**متن پررنگ**` و `*متن مورب*`
- فهرست: هر خط با `- ` شروع شود
- نقل‌قول: خط با `> ` شروع شود
- لینک: `[متن لینک](https://example.com)`
- تصویر داخل متن: `![توضیح](/media/photos/x.jpg)`

## نکات

- تصاویر و PDF واقعی کارخانه، جایگزین فایل‌های Placeholder فعلی (`placeholder-*.svg` و `*.txt`) شوند.
- اطلاعات تماس/آدرس/تلفن واقعی در فایل `apps/web/lib/company-info.ts` قرار می‌گیرد (یک نقطهٔ واحد).
